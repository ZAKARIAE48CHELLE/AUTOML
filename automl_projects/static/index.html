Where It Plugs Into D:\EMSI\5emme\AUTOML Microservices

End-to-end call flow across your 4 team services (`e1` -> `e2` -> `e3` -> `e4`).

E1 · DATA SERVICE
services/e1-data-service
GET /datasets/{id} · POST /splits

Extracts dataset profile, missing ratios, and split Parquet/CSV paths passed to Stage 1.

E2 · TRAINING HUB (PRIMARY TARGET)
services/e2-training-service
MODELS_CATALOG · POST /training/jobs

Registers the library spec in MODELS_CATALOG and delegates execution to adapters/<lib>_adapter.py.

E3 · ASSISTANT SERVICE
services/e3-assistant-service
POST /assistant/proposals

Uses constraint rules & Arbitrator logic to recommend the optimal library & explain SHAP/leaderboard winners.

E4 · WORKFLOW STUDIO & UI
services/e4-studio-service & apps/web
train.model · train.tune · Export

Triggers DAG nodes (`POST /training/jobs`), streams SSE events, and packages exports from `e2` artifacts.
